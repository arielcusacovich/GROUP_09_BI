# W1 and C1 project history

Our earlier submissions are preserved in GROUP_10_W1.zip and GROUP_09_C1.zip. Their original notebooks, reports, presentations, data extracts, prepared data, tables and figures are unchanged. They are compressed only to make browser uploading practical. Extract an archive to inspect its original folder structure.

Our group is 09. The earlier Group 10 labels were incorrect. C1 slide 5 retains its original mistaken 19.17% figure; the current correction and supporting calculations are in W2 section 4.

Identical national source ZIPs, the dictionary and source register are shared with the current project's data/source folder rather than duplicated in each historical archive. The national ZIPs are included in the complete offline package; the main README also supplies their official URLs. To rerun a historical notebook, copy the shared source files into that historical project's data/source folder.

preservation_manifest.json maps every supplied W1/C1 file to its preserved location. For archived files, archive_member identifies the file inside the ZIP, and sha256 is the fingerprint of that extracted file. For shared sources, the fingerprint refers to the source file itself.
